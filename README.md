# ระบบแผนที่และตรวจสอบแปลงที่ดินดิจิทัล (ต้นแบบ)

ต้นแบบเว็บ (Mobile-first) สำหรับค้นหาแปลงที่ดินและดูการซ้อนทับของเขต บนแผนที่ภาพดาวเทียม  
**ข้อมูลทั้งหมดเป็นข้อมูลจำลองเพื่อการเรียนรู้** ไม่ใช่การรับรองสิทธิ์ตามกฎหมาย และไม่ใช่ระบบทางการของหน่วยงานใด

## หน้าจอ
- S01 แผนที่หลัก (ภาพดาวเทียม + 4 ชั้นข้อมูล)  - S02 ค้นหาแปลง  - S03 ผลแปลง

## ลองค้นหา
| เลขโฉนด | ผล |
|---|---|
| 10001 | ไม่ซ้อนทับ |
| 10002 | ซ้อนทับเขตป่าสงวน |
| 10003 | ซ้อนทับเขตปฏิรูปที่ดินและอุทยานฯ |
| 99999 | ไม่พบแปลง |

พิกัดตัวอย่าง: `19.1746, 99.9844` (แปลง B) · ดูหน้าโหลดไม่สำเร็จ: ต่อท้าย URL ด้วย `#map-error` หรือ `#result-error`

## วิธีรัน
เปิดผ่านเว็บเซิร์ฟเวอร์ เช่น `python3 -m http.server` แล้วเข้า http://localhost:8000  
หรือเผยแพร่บน GitHub Pages: Settings → Pages → Branch `main` / root

## เทคโนโลยีและแหล่งภาพ
HTML/CSS/JavaScript ล้วน + [Leaflet](https://leafletjs.com) · ภาพดาวเทียม Esri World Imagery (ต้องมีอินเทอร์เน็ต และแสดงเครดิตตามเงื่อนไขของ Esri)  
ภาพจำลองสำรอง `assets/fallback-satellite.jpg` ใช้แสดงเมื่อโหลดภาพดาวเทียมไม่ได้ (สร้างขึ้นเอง ไม่ใช่ภาพจริง)  
ภาพดาวเทียมเป็นพื้นหลังประกอบเท่านั้น ขอบเขตแปลงและเขตเป็นข้อมูลสมมติ

## พื้นที่ตัวอย่าง
กรอบแผนที่อยู่ที่จังหวัดพะเยา (ละติจูด 19.12–19.22, ลองจิจูด 99.92–100.02 ทางตะวันออกของกว๊านพะเยา)  
แปลงและเขตทั้งหมดเป็นข้อมูลสมมติ ไม่ตรงกับแปลงหรือเขตจริง และภาพสำรองใน `assets/` ไม่ใช่ภาพของพื้นที่จริง  
เลื่อนพื้นที่ได้โดยแก้ `LAT0`, `LNG0` ที่บรรทัดบนสุดของ `js/app.js`
